![Virtual AI Assistant](/virtual-assistant.png)

A smart virtual assistant designed to answer user queries in real-time using DialogFlow's NLU capabilities, backed by Firebase and NodeJS. Built with the aim of improving user engagement and automating repetitive college-related inquiries.

Originally developed to assist prospective students and their parents during the admission process at PCCOER, it helps reduce faculty workload by automating frequently asked questions with voice, text, and graphical responses.

## 📋 Features

- ✅ Real-time conversational interface
- ✅ Text + Voice + Visual response
- ✅ Context-aware dialogue handling
- ✅ Integrated with Firebase backend
- ✅ Custom web UI for better engagement
- ✅ Designed for admission-related FAQs
- ✅ Powered by DialogFlow NLU
- ✅ Easily extensible knowledge base
