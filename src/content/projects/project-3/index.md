**CodeBy** is a real-time collaborative, web-based code editor that allows multiple users to edit code simultaneously with minimal latency and a rich set of features.

Built using NodeJS and Socket.IO for a robust backend supporting low-latency, bi-directional communication. Redis handles efficient data persistence, while the frontend is crafted with React to deliver a smooth user experience.

## 📋 Features

- ✅ Real-time collaborative code editing  
- ✅ Multi-user support with low-latency updates  
- ✅ Efficient backend using NodeJS + Socket.IO  
- ✅ Data persistence with Redis  
- ✅ Clean and intuitive React-based UI  
- ✅ Code sharing and session syncing  
- ✅ Scalable architecture for teams and classrooms  

## 🧠 Technologies Used

- NodeJS  
- Socket.IO  
- Redis  
- React (Frontend)
