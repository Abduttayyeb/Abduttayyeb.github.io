**Phonix Grammar Companion** is a Progressive Web App (PWA) designed to make grammar engaging and accessible for kids aged 5–14. It offers grammar-based interactive games and an AI-powered chatbot to assist in real-time learning.

Built with **ReactJS** for the frontend, **Firebase** for real-time data management, and **NodeJS** on the backend, it ensures a smooth and responsive user experience.

- 🏆 Selected for **Power Judging Round Grand Finale** at **Toycathon 2021**, a national-level hackathon by the Indian government.

## 📋 Features

- ✅ Fun, educational grammar games for ages 5–14  
- ✅ AI-powered chatbot for real-time assistance  
- ✅ Responsive and kid-friendly UI  
- ✅ Works offline (PWA)  
- ✅ Real-time sync with Firebase  
- ✅ Voice interaction capabilities (optional)
